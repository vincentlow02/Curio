# Curio — Tokyo Collectible Research Agent

Curio identifies collectibles from images or text, researches public Japanese marketplace listings, calculates a repeatable online asking-price reference, and suggests Tokyo areas worth checking.

**Live demo:** [curio-web-production-49c7.up.railway.app](https://curio-web-production-49c7.up.railway.app)

The application is implemented in [`qwen-spike/`](./qwen-spike). See the [full project README](./qwen-spike/README.md) for architecture, setup, security, testing, and Railway deployment instructions.

Core stack: Next.js, TypeScript, Qwen Cloud, Playwright, deterministic Node.js pricing, Daytona sandbox verification, and a tightly budgeted Tavily fallback.
